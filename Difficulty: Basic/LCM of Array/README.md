<h2><a href="https://www.geeksforgeeks.org/problems/lcm-of-given-array-elements3919/1">LCM of Array</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an array <strong>a[]</strong> of <strong>n</strong> numbers, find the Least Common Multiple (LCM) of all the elements of the array. </span><span style="font-size: 18px;">The LCM of an array is the smallest number that is divisible by every element of the array.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong> </span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>a[] = [1, 2, 8, 3]
<strong>Output: </strong>24
<strong>Explanation: </strong></span><span style="font-size: 18px;">LCM of 1, 2, 8 and 3 is 24 since 24 is the smallest number divisible by all of them.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>a[] = [1, 8]
<strong>Output: </strong>8
<strong>Explanation: </strong></span><span style="font-size: 18px;">LCM of 1 and 8 is 8 since 8 is the smallest number divisible by both.</span>
</pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 &lt;= n &lt;= 10<br>1 &lt;= a[i] &lt;= 20</span></p>
